# Portafolio de Lucciano Zepeda

Sitio estático inicial preparado para GitHub Pages. Idioma: español. Diseño: Swiss Experimental / Kinetic Portfolio, negro, blanco cálido y lima.

## Archivos
- `index.html`: contenido y secciones.
- `style.css`: diseño, colores, tipografía y adaptación a celular.
- `script.js`: interacciones y comportamiento futuro.

## Cómo publicarlo
Subir los archivos a la raíz del repositorio público en GitHub. Ir a **Settings > Pages > Build and deployment**, elegir **Deploy from a branch**, rama **main**, carpeta **/(root)** y guardar.

## Pendientes antes de lanzar el portafolio definitivo
- Confirmar nombre/cargo/biografía y disponibilidad laboral.
- Reemplazar las tarjetas de demostración por proyectos reales con autorización.
- Añadir CV descargable, correo de contacto y perfiles profesionales.
- Crear páginas individuales para los casos de estudio.
- Revisar textos y enlaces en celular y escritorio.

**Nota:** Los proyectos, textos de presentación y disponibilidad no se deben presentar como datos definitivos hasta validarlos con Lucciano.
