# Portafolio Lucciano Zepeda — V02

Portafolio estático para GitHub Pages, en español. Incluye portada, tres proyectos con páginas individuales, sobre mí, experiencia, herramientas, contacto y CV en español e inglés.

## Publicar en tu repositorio `lucciano`

1. Abre `https://github.com/javiera-atala/lucciano`.
2. **Importante:** en esta actualización, sube los archivos y la carpeta `proyectos` y `cv` respetando su ubicación. GitHub desde el navegador puede aceptar arrastrar carpetas; si no, usa `Add file → Create new file` y especifica rutas como `proyectos/lemu.html` para crear la carpeta automáticamente, o GitHub Desktop para subir todo junto.
3. Sobrescribe `index.html`, `style.css`, `script.js` y `README.md` existentes, conservando esos nombres exactos.
4. Agrega las páginas de `proyectos/` y los PDF de `cv/`.
5. `Settings → Pages` debe tener `Deploy from a branch`, rama `main` y carpeta `/ (root)`.
6. URL: `https://javiera-atala.github.io/lucciano/` (la actualización puede tardar unos instantes en aparecer; recarga sin caché).
